MELVIN & ELLEN WEDDING WEBSITE

Files:
- index.html: the full responsive wedding invitation website
- assets/: the supplied couple photographs and reference invitation
- wedding.ics: calendar events for the ceremony and reception

PREVIEW LOCALLY
Open index.html in a modern browser. Internet access is used for Google Fonts and map links; the website itself does not require a build step.

PUBLISH WITH GITHUB PAGES
1. Create a new GitHub repository, for example Melvin-Ellen-Wedding.
2. Upload index.html, wedding.ics, and the entire assets folder (keep the folder structure unchanged).
3. In the repository, open Settings > Pages.
4. Under Build and deployment, select Deploy from a branch; choose main and /(root), then Save.
5. Wait for GitHub Pages to publish and open the generated website URL.

CHECK BEFORE PUBLISHING
- Confirm the venue pins and map directions for Olympia SDA Church and Fallsway Events.
- Confirm RSVP contact details and whether RSVP should go to Joseph or Grace first.
- The gift request and colours follow the information provided: monetary gifts K500 and above; magenta, purple, mint green and gold.
